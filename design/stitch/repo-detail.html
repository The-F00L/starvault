uv: An extremely fast Python package manager

uv is an extremely fast Python package and project manager, written in Rust. Designed as a drop-in replacement for pip, pip-tools, and virtualenv.

Benchmark: Warm Cache Installation (Trio of packages)

Time in milliseconds (lower is faster). Tested on macOS Apple Silicon M3 Max.

~80x faster
uv (0.5.11) 24ms
rye (0.39.0) 198ms
poetry (1.8.2) 1,420ms
pip (24.0) 1,960ms

Installation

Install uv via the standalone installer, Homebrew, or cargo:

Standalone installer (macOS / Linux) copy 
curl -LsSf https://astral.sh/uv/install.sh | sh
Pip Drop-In Execution copy 
# Install fastapi and uvicorn at lightning speed
uv pip install fastapi uvicorn[standard]

# Create virtual environment
uv venv .venv
source .venv/bin/activate

Key Architectural Highlights

  • Universal resolution engine: Resolves dependencies using PubGrub algorithm with full backtrack support.
  • Disk-space optimized: Global deduplication cache using hardlinks on supported filesystems.
  • Python management built-in: Can automatically install pinned Python runtimes on demand.
